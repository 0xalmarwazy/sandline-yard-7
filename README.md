SANDLINE — Yard 7: a round-based tactical FPS that runs offline in a desktop browser. Two teams of three, bots that move, see and shoot back, a bomb to plant and defuse, money earned each round and spent in a buy menu, on an original map — built on three.js 0.187.0 with no build step and no network request.

## Play it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Build the submission outputs

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
